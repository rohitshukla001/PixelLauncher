Drop photo wallpapers here (.jpg, .jpeg, .png or .webp).

- Each image file in this folder becomes a wallpaper in the app, shown
  before the built-in code-drawn ones, in alphabetical order.
- Use portrait images at least the size of a phone screen
  (about 1080 x 2400). They are centre-cropped to fit.
- Add only images you own or have the right to use. None ship by default.
- This README is ignored (only image files are listed).
